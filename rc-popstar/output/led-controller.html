Diagram

Killerbody 48102 LED control box wiring. The box reads TWO existing signals via Y-cables — it does NOT use a spare channel.
CH1 Y-cable: Receiver CH1 splits to D-Box3 gyro input AND Killerbody CH1. The box reads steering direction for left/right blinker activation.
CH2 Y-cable: Receiver CH2 splits to XD10 Pro ESC AND Killerbody CH2. The box reads throttle for forward/brake/backward light states.
BEC supply: from XD10 Pro ESC (6V/7.4V to receiver and all servos). DO NOT connect a separate BEC to the receiver — per XD10 Pro manual this will damage the ESC.
Channel map for the RC6GS V3 / R7FG:
CH1 (steering) → D-Box3 gyro + Killerbody CH1 (Y-cable)
CH2 (throttle) → XD10 Pro ESC + Killerbody CH2 (Y-cable)
CH3 (aux knob) → available (future: sound module throttle sense)
CH4 (aux) → D-Box3 gyro gain control (optional)
