body-harness

Diagram

Body-shell wiring: magnetic contact interfaces at each corner route LED power to headlight and tail/brake assemblies in the custom E36 cabriolet body. Each IFACE_*_BODY mating pair consists of: satellite magnet (LED+ anode) + body post magnet (GND cathode return). Current limiting via inline resistors: headlights (white) = 100 ohm, tail/brake (red) = 150 ohm. See docs/magnetic-contact-design.md for magnet spec and body-side install.
