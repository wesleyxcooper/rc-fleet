## Car 2 — HPI Nitro RS4 3 Drift (Nitro 4WD Outdoor)

Used car. Parking lot drifter. Engine forward of center for weight bias, single-speed
transmission, hard compound drift tires. Nitro tuning is part of the appeal. Parts
availability is declining (HPI bankruptcy/relaunch) so inspect carefully before buying.

- HPI Nitro RS4 3 Drift Conversion Kit Used — $280 Buy It Now + $49 shipping
- Nissan Skyline GT-R body/shell listings — $150–590
- Bare/project cars — $20–170

Target: **$150–200 for a complete runner**. A runner in that band exists; set a saved search and be patient.

**What to look for in a used buy:**
- Engine turns over freely (not seized — a seized G3.0 is a parts car)
- Pullstarter retracts properly
- Driveshafts intact front and rear
- Steering servo functional
- Clutch bell not cracked
- Fuel tank not cracked (common failure point)
- Ask if it was run on the correct nitro fuel % (20–30% is typical)

### Radio Note

If you buy the RS4 3 Drift RTR it comes with HPI's old 2-channel radio. It works but
is very basic. When you buy the Radiolink RC6GS V3 for the Stage-D10, you can bind a
second Radiolink receiver to it and use ONE transmitter for both cars. This saves
~$75 and means one radio to learn.
